# About

Simple script that will setup Proxmox LXC container start and stop for specified times with cron.

# Use
Run on the host as root:
```sh
bash <(curl -fsSL https://raw.githubusercontent.com/SimplyProgrammer/Proxmox-LXC-start-stop-scheduler/main/lxc-schedule.sh)
```

Or use flags like:
```
bash <(curl -fsSL https://raw.githubusercontent.com/SimplyProgrammer/Proxmox-LXC-start-stop-scheduler/main/lxc-schedule.sh) --list
```
